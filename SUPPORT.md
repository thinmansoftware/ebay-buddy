response time is promised. The public repository and marketplace listing are
pending publisher approval; use the issue tracker of the actual published
Thin Man Software repository once available, not a similarly named project.

Report the reviewed version, transport, runtime versions, a sanitized error code
and steps reproduced with synthetic data. Never include credentials, headers,
tokens, mail bodies, buyer details, order references, private artifacts or logs
that contain them in public issues. Do not send a security report containing
private details to a public issue. Contact admin@thinmansoftware.com privately
with a sanitized summary first; agree a secure reporting route before sharing
sensitive evidence. This is the existing company contact, verified on the public
Thin Man Software homepage October 28, 2026. No automatic telemetry or support upload is included.

For setup and removal see README.md, GROK_SETUP.md and PRIVACY.md. Your assistant
host, eBay developer account and hosting provider have their own support and
access policies. Provider availability, quotas, seller claims, ended listings
